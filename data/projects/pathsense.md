## What it is

PathSense is an indoor navigation app for blind and low-vision users. It provides spoken guidance through buildings where GPS does not work.

## The problem

Outdoor navigation is solved by satellite positioning. Indoors, a user needs a map and a position, and neither is usually available.

## What makes it interesting

It was a finalist at Hack the North 2024. The project targets the last few meters, which is where wayfinding actually fails.

## What you can learn

Indoor positioning is an infrastructure problem before it is an app problem. Someone has to map the building.

## Limitations of this analysis

The record does not describe the positioning method or any user testing.
