## What it is

Selene is a web application that maps moonquakes in interactive 3D. It plots seismic events from the Apollo missions on a model of the Moon.

## The problem

The Apollo seismometers returned years of data, but it lives in archives formatted for specialists. A map is a faster way to see where the Moon moved.

## What makes it interesting

It won the Galactic Impact award at NASA Space Apps 2022. The project is an interface over public data, which is a category Space Apps rewards.

## What you can learn

The same dataset can support several products. A visualization is a legitimate contribution when the raw archive is effectively unusable.

## Limitations of this analysis

The record does not link the app or describe how the seismic events are geolocated.
