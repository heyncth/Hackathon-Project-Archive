## What it is

BioJS is a JavaScript library for visualizing biological data in the browser: sequences, alignments, trees, and interaction networks.

## The problem

Bioinformatics tools were often desktop applications or Python scripts. Sharing a result meant sending a file and asking the reader to install something.

## How the experience works

A developer imports a component, passes it data, and gets an interactive view in the page. Components are small and composable, so a paper's supplementary page can show the data directly.

## What makes it interesting

In the 2014 Google Summer of Code, all five students stayed on as core developers and designed version 2.0. A summer program became the maintainer pipeline.

## What you can learn

Open-source projects die when the original author leaves. Funding contributors, not just code, keeps a library alive.

## Limitations of this analysis

The record does not cover the component architecture or the current maintenance status.
